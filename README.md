# Parcours Canada

Plateforme d'**information générale** sur l'immigration au Canada, en français, pour la communauté djiboutienne.

## Contenu
- Guide 1 — Entrée express expliqué simplement
- Guide 2 — Les étapes d'un dossier
- Guide 3 — Les documents habituellement demandés
- Sections : cours vidéo (à venir), webinaires d'information, s'installer au Canada, partenaires, avertissement légal

## Cadre légal (important)
Information éducative seulement — **aucun conseil personnalisé, aucune représentation**.
Au Canada, l'art. 91 de la LIPR réserve le conseil en immigration contre rémunération aux représentants autorisés (avocats, notaires du Québec, consultants réglementés membres du Collège — CRCI).
Un partenaire réglementé est en cours de recrutement pour les services personnalisés, offerts séparément.

## Technique
Site statique (`index.html` autonome), hébergé gratuitement via GitHub Pages.
Les vidéos vivent sur YouTube (intégrées), les produits payants sur Payhip — rien de tout cela n'est stocké ici.

Créé en octobre 2026, Ottawa.
